## 🛡️ lookOut — AI Security & Intrusion Detection System

A computer-vision security system that detects and tracks people, monitors a virtual security boundary, captures intrusion evidence, and sends events through a complete backend and monitoring pipeline.

```text
Camera
  ↓
OpenCV
  ↓
YOLO11n
  ↓
ByteTrack
  ↓
Intrusion Detection
  ↓
Evidence Capture
  ↓
FastAPI
  ↓
PostgreSQL
  ↓
React Dashboard
```

### Key Features

- 👤 Real-time person detection using **YOLO11n**
- 🎯 Object tracking using **ByteTrack**
- 🚧 Track-based virtual boundary intrusion detection
- 📸 Full-frame and cropped-person evidence capture
- ⚡ REST API built with **FastAPI**
- 🗄️ Intrusion and camera persistence with **PostgreSQL**
- 📹 Camera-linked intrusion events and camera status monitoring
- 🖥️ Monitoring dashboard built with **React**
- 🐳 Containerized backend infrastructure with **Docker**
- 🧪 Automated testing using **pytest**
- 🔄 CI workflow using **GitHub Actions**

> ByteTrack IDs represent tracked objects within a video stream — they are not person identities or face recognition.

**Tech:** `Python` `OpenCV` `YOLO11n` `ByteTrack` `FastAPI` `PostgreSQL` `React` `Docker` `pytest` `GitHub Actions`

## 🐍 VIPER — Programming Language + RAG Assistant

A custom programming-language project combining **compiler construction concepts** with an AI-powered documentation assistant.

### Programming Language

VIPER includes its own:

- 🔤 Lexical rules and tokens
- ⚙️ Data types
- ➕ Arithmetic, relational, logical and assignment operators
- 🌳 Context-Free Grammar (CFG)
- 🔁 Control-flow syntax
- 🧮 Expression grammar and precedence
- 🧠 DFA-based lexical analysis
- ⚠️ Defined lexical error handling

Example VIPER concepts include:

```text
HOLD ... RELEASE

fang    → integer
venom   → float
scale   → character
coil    → string
hiss    → boolean
```

### RAG Assistant

VIPER documentation is also used as a knowledge base for a **Retrieval-Augmented Generation (RAG)** assistant.

```text
VIPER Documentation
        ↓
Document Processing
        ↓
Embeddings / Vector Store
        ↓
Retrieval
        ↓
LLM
        ↓
VIPER Assistant
```

The workflow explores **n8n automation, vector retrieval and LLM-based question answering**.

**Tech:** `Compiler Construction` `CFG` `DFA` `RAG` `LLMs` `Vector Search` `n8n`
